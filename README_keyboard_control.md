# X500 + SO-101 键盘控制

本版本仅操作 MuJoCo，不连接真实无人机、PX4 固件或 ROS。旧模型、控制脚本和资源未被覆盖。
没有安装软件，没有修改 Conda、环境变量或 PyCharm 配置。

## 启动文件与中文 PyCharm 操作

不需要手动点击 Load key。单独打开 XML 不会运行键盘控制、飞行闭环或实际转速气动力计算。

1. 顶部运行配置下拉菜单 → **编辑配置… → ＋ → Python**。
2. 名称填写英文 **X500_SO101_Keyboard_Control**。
3. 解释器选择已有的：`C:\Users\hunter\.conda\envs\mujoco-env\python.exe`。
4. **脚本路径**填写上述 `keyboard_control_x500_so101.py` 的完整路径。
5. **工作目录**填写：`D:\fangzhenmoxing\fangzhenmoxing\PX4\x500_so101_mujoco`。
6. **脚本形参留空 → 应用 → 确定 → 运行**。
7. 先点击打开的三维窗口，使其获得键盘焦点，再操作。不是在 PyCharm 编辑器或控制台里按键。

初始状态为起落架着地、六关节收起、旋翼静止。没有自动起飞或按时展开流程。
按住 W 约 2 秒完成电机缓升，继续按住才开始上升；达到希望的高度后松开。
若尚未离地就松开 W，会取消启动并渐停电机，不会按旧时间表自行起飞。

## 按键

| 按键 | 操作 |
| --- | --- |
| W / S | 按住上升 / 下降，松开后平滑制动并保持高度 |
| ↑ / ↓ | 按住前进 / 后退 |
| ← / → | 按住向左 / 向右平移 |
| Q / E | 按住机头向左 / 向右转 |
| 1 | 肩部旋转 so101_shoulder_pan，正向 |
| 2 | 肩部俯仰 so101_shoulder_lift，正向 |
| 3 | 肘部 so101_elbow_flex，正向 |
| 4 | 腕部俯仰 so101_wrist_flex，正向 |
| 5 | 腕部旋转 so101_wrist_roll，正向 |
| 6 | 夹爪 so101_gripper，正向为张开 |
| Shift + 1—6 | 对应关节反向；Shift + 6 关闭至原收起角附近 |
| U | 申请已经过路径检查的分段向下展开，需收起状态且 base_link 高于地面 1 米 |
| F | 申请安全收起，规划失败则拒绝；已收起时不额外运动 |
| L | 申请完整降落：必要时先验证并执行收起路径，再下降、接地、卸载、停桨 |
| 空格 | 暂停 / 继续整个物理仿真；这与悬停不同 |
| R | 重置到地面初始状态，仅用于调试，不是实际降落 |
| Esc / 关闭窗口 | 退出仿真，不会自动完成降落 |

数字键使用主键盘区 1—6，小键盘 1—6 也支持。按实际 GLFW 键码处理，不依赖 Shift 后生成的字符。
前后左右以当前机头（模型 +X）为准，左为机身 +Y；转动摄像机不改变操作方向。
方向键松开后平滑停止，再保持制动后的地点。可以 W＋↑ 组合移动，斜向速度经过归一化。
相反指令同时按下会抵消。机械臂松键后保持关节目标角，不改写实际关节位置。

推荐首次操作：保持机械臂收起 → W 升到 1 米以上 → 松键等待稳定 → U 展开 → 数字键逐关节试动 → 松开所有关节键 → L 请求收起及降落。
U 和 F 是辅助路径，不是任意姿态都可用的全局运动规划器。手动关节输入在辅助路径执行期间不接管目标。
L 遇到正在执行的辅助路径时会提示等待，结束后需再按 L。机械臂仍在运动时，先松键等待制动再请求 F/L。

窗口失焦会清除所有持续按键，飞行参考逐渐制动；降落下降会取消并转为保持。
辅助机械臂轨迹沿已验证路径减速停止，不会在重新获得焦点时自动恢复。需要重新请求 U/F/L。
重新获得焦点后，先松开再重新按下所需键。空格与 R 同样会清除残留按键状态。

## 窗口区别

使用现有 GLFW 和 MuJoCo 官方渲染 API 创建专用窗口，支持按下/松开、失焦、鼠标左键旋转和滚轮缩放。
首版没有原生 Simulate 左右控制面板；状态和帮助显示在画面上，不与原生数字键快捷键争用。
摄像机随无人机平移，默认距离 2.4 米，可滚轮缩放。
状态文字使用英文，避免渲染器字体无法显示中文；中文含义见本说明。
为减少渲染开销，窗口关闭阴影、反射显示，碰撞和动力学不变。仿真使用自己的时间步，电脑慢时会慢于墙钟时间。

## 操作参数与实际动力上限

| 参数 | 已确认操作上限 | 本版本持续指令值 |
| --- | ---: | ---: |
| 总水平速度 | 0.30 m/s | 0.20 m/s |
| 上下速度 | 0.20 m/s | 0.18 m/s |
| 偏航速度 | 15°/s | 12°/s |
| 机身倾斜 | 10° | 期望倾斜限制 8°，实际超过 10°触发故障暂停 |

初测中闭环存在速度超调，因此指令留有余量，保证已测操作的实际峰值低于约定上限；没有提高动力上限。
平移、竖直参考加速度上限 0.15 m/s²；偏航参考加速度上限 20°/s²。
手动关节速度上限 10°/s、加速度上限 30°/s²。辅助轨迹使用五次多项式，正常执行速度上限 30°/s、加速度上限 60°/s²；
失焦时还包括有限的轨迹时间缩放制动项。辅助展开约 15.5 秒，比原自动演示更慢。
这些是操作和规划参数，不是硬件额定参数。不同组合指令、外部扰动及任意机械臂姿态未获得形式化全局速度保证。

默认高度操作上限为 base_link 距地面 2 米，在接近上限时按制动距离减速。
这是程序的操作边界，不是初始位置加两米。初始位置仍是原模型约 0.2285995 米。

原模型物理参数全部保留：

- 总质量约 2.696313692 kg，重力 9.81 m/s²，自由关节保留，物理步长 0.00025 秒。
- 外环/参考更新 250 Hz，电机及气动力每物理步更新 4000 Hz，画面目标约 60 Hz。
- 六关节力矩上限依次为 `[0.4,1.0,1.2,0.35,0.15,0.08]` N·m，原 kp、kv 和模型限位不变。
- 每路旋翼转速上限 1000 rad/s，气动力上限 8.54858 N，轴力矩上限 ±2.26 N·m。
- ±2.26 N·m（含主动制动）沿用此前批准的仿真假设，不是已核实硬件额定参数。
- kf=8.54858e-6、km=0.016、上/下降响应 0.0125/0.025 秒沿用原模型记录。
- 气动力按实际旋翼关节转速计算：`F=spin*kf*omega*abs(omega)`，正确转向时即 kf×omega²。
- 空气阻力矩施加在旋翼刚体上，轴电机反作用由关节动力学承担，没有重复给机身添加反扭矩。

飞行控制使用当前位置参考、速度参考及当前浮动基座质量矩阵，计入机械臂运动的重心、惯量、反作用变化。
关节继续使用原有有限力矩 position actuator，加入模型前馈和目标速度补偿。
只更新控制参考与 actuator ctrl，不逐帧改写实际 qpos/qvel。R 的关键帧重置和独立预测数据是明确的例外。

## 关节与保护

初始六关节角度依次为 `[70,-179,178,66,100,0]`°。
六个关节在各自局部坐标系均为 +Z 轴铰链，绝对角度需考虑原模型 ref 和已旋转的连杆变换。
操作范围在模型合法范围内保留约 1°余量；夹爪使用原收起 0°到已确认张开 99°。
0°不代表两指已经完全贴合，不能把闭合角度当作已成功夹住物体。

地面及 base_link 高度不足 1 米时拒绝手动关节运动；关节没有被物理锁住，有限执行器仍可响应外力。
S 在机械臂未收起时检查最低点与地面间距，保留减速余量；接近地面后建议用 L 完整降落。

预测器使用独立 MjData，不覆盖实际仿真状态。检查：

- 原碰撞几何之间的距离、关节限位与制动位置；
- 整个桨叶扫掠区域，不只检查当前桨叶角度；
- 机械臂保守边界与地面间距，预测姿态至少留 0.10 米；
- 静态重力力矩是否超过现有限制的 85%，保留运动余量。

原收起姿态与起落架的最小相关凸碰撞间距约 1.643 毫米，因此通用近碰保护间隙取 0.8 毫米，另计制动位移和 40 毫秒参考余量。
该数值不修改实际模型的碰撞几何或接触设置，也不是实机制造公差。预测检查不是对所有可能姿态、速度与扰动的绝对无碰撞证明。
组合关节指令无法通过检查时会整体制动并提示，可能无法只让其中一个关节继续。
观察到异常接触、非有限状态、超过 10°倾斜或超过 12°关节跟踪误差时，窗口进入故障暂停。建议 R 重置检查。

L 会尝试几条有限的收起候选路径，逐段采样验证。无法验证则保持飞行并提示，不盲目插值回收。
下降速度在接近起落架着地位置时减小。停桨前要求两条滑橇均有实际正接触力、低速度和接近水平，并持续满足稳定条件 0.5 秒。
极小接触力会在滑橇角点间切换，使用 80 毫秒的接触保持判据；随后用 1.5 秒卸载推力，最终承重另行验证。
停桨是实际有限力矩制动过程，未直接置零旋翼速度。
